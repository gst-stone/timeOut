

一款以“寿元”为核心资源的东方修仙单机游戏原型，使用 Godot 4 开发。

## V1 原型

当前已经形成完整的第一轮核心循环：

- 命格随机生成
- 修炼与寿元消耗
- 九大境界 / 十二层突破
- 三个探索区域
- 随机妖物遭遇
- 玩家与妖物 2D 精灵
- 战斗 HP / 受击反馈
- 自动战斗与撤退
- 装备掉落与装备栏
- 功法学习
- 灵石资源
- 死亡判定
- 轮回永久属性成长
- JSON 本地存档 / 读取
- 自动保存
- 水墨国风 2D UI

## 核心玩法

玩家从十八岁开始一世修行。

每一次修炼、探索、战斗都会消耗时间；寿元耗尽或者战斗失败后，这一世结束。

死亡并不是单纯的 Game Over：根据上一世的修行境界与层数，会沉淀为永久的悟性、气运、体质，让下一世拥有更高的成长上限。

因此核心循环是：

`命格 → 修炼 → 探索 → 战斗 → 突破 → 寿元耗尽 → 轮回 → 永久成长 → 下一世`

## 技术

- Godot 4.x
- GDScript
- 2D UI / 水墨国风视觉方向
- SVG 精灵素材
- 不依赖第三方运行时库

## 运行

使用 Godot 4.x 导入本仓库，打开 `project.godot`，运行项目即可。

主场景当前使用 `MainV2.tscn`。

## 当前视觉素材

`assets/` 中已经加入玩家与多种妖物的 2D 水墨风精灵：

- 玩家修士
- 山野狼妖
- 黑鳞蛇妖
- 赤焰虎
- 铁甲妖熊

战斗时会根据遭遇的妖物自动切换精灵。
