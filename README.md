# 寿元将尽

一款以“寿元”为核心资源的东方修仙单机游戏原型，使用 Godot 4 开发。

## 当前版本

MVP 目标：

- 修炼
- 境界与突破
- 外出探索
- 随机遭遇战
- 灵石奖励
- 寿元消耗
- 死亡
- 轮回

## 技术

- Godot 4.x
- GDScript
- 2D UI / 水墨国风视觉方向
- 当前版本不依赖第三方素材，先保证项目可以直接打开和迭代

## 运行

使用 Godot 4.x 导入本仓库，打开 `project.godot`，运行项目即可。
