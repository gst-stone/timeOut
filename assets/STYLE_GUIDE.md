# V2 视觉规范

`1.png` 是本项目 V2 的视觉参考。代码层面统一采用东方修仙、纸张/墨色、低饱和青灰与土褐色的方向。

## 视觉原则

- 背景：暖灰纸张，不使用纯白。
- 主墨色：深青黑，用于标题、重要信息。
- 辅助墨色：灰青，用于说明文字。
- 强调色：青灰蓝，用于主要行动。
- 次强调色：土褐，用于轮回、危险、次级操作。
- 危险色：暗朱红，仅用于 HP、死亡、受击反馈。
- 面板：圆角、细边框、轻阴影，避免现代 SaaS 卡片感。
- 控件：减少渐变和高饱和色，强调纸张、墨线和印章感。

## 资源方向

现有 SVG 精灵继续保留作为占位资源；后续正式美术资源应保持统一的角色比例、轮廓和墨色层次。

## 适用范围

主界面、战斗、死亡结算、轮回天赋、奇遇弹窗、装备与功法面板均应遵守该规范。
